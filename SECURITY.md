## Reportar una Vulnerabilidad o Fuga de Información

La seguridad e integridad de la comunidad es una prioridad máxima. Si identificas una vulnerabilidad de seguridad en los scripts de compilación, en los pipelines de GitHub Actions o detectas una clave/token sensible accidentalmente expuesta en algún manual:

1. **NO abras un issue público** para no exponer la vulnerabilidad.
2. Utiliza la función oficial de **Private Vulnerability Reporting** de GitHub disponible en la pestaña [Security Advisories](https://github.com/sajitario2004/manualGit/security/advisories/new) del repositorio.
3. Proporciona una descripción detallada del problema, los pasos para reproducirlo y cualquier sugerencia de mitigación.

Agradecemos enormemente tus esfuerzos de divulgación responsable para mantener seguro a todo el ecosistema.
